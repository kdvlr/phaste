# 0007. React SPA with Vite and Tailwind Material 3 Design Tokens

We chose a single-page application architecture built with React, Vite, and Tailwind CSS incorporating Material 3 (MD3) design tokens (tonal palettes, state layers, rounded shapes, and typography scales). The compiled static SPA bundle is served directly by the FastAPI web service, keeping deployment simple with a single application container that manages both API endpoints and the responsive web client.
